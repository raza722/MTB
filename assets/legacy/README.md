# Images from the old desktop system (archive)

Kept so nothing from the old software is lost. Brand files to use are in `../brand`.

- `app-resources/`: the WinForms app's `Resources` folder (233 images: menu icons, backgrounds, logos), copied as they were.
- `report-images/`: every picture embedded in the old `.rdlc` report designs (225 designs, 63 distinct pictures), one
  file each, named `<name in the report>-<hash>.<ext>`. `report-images/index.json` lists which reports used each picture.

The old software was a product also sold to other schools, so some report designs still carry **other schools' logos**
and headers (for example `logo2-*` "Excel School of the Educators", `iiuiSchool-*` "IIUI Schools", `elixirheader*`,
`Arabpackages-*`). Do not use those for MTB. The MTB crest is `mtb1-d9eb22fc.png` (= `../brand/mtb-crest.png`).

No personal data here: student, guardian and staff photos are in `backend/uploads` (never committed).
